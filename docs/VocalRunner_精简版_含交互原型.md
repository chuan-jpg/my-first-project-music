# VocalRunner 产品说明 + 交互原型（精简版）

## 一、产品概述

### 这是什么
VocalRunner 是一款**用跑酷游戏的方式练习唱歌音准**的 Android App。用户对着手机唱歌，App 实时识别音高，控制游戏角色在"音符台阶"上移动——唱准了角色落在台阶上，唱偏了角色越过或穿过台阶。

### 解决什么问题
传统音准练习工具（如 Singscope、钢琴校音 App）存在三个痛点：
1. **枯燥**：对着频谱图唱歌，缺乏反馈和动力
2. **门槛高**：需要看懂五线谱和音高曲线
3. **无进度**：唱完不知道哪里准、哪里不准，无法针对性练习

VocalRunner 把音准练习变成游戏：
- 用"角色移动 + 台阶"替代抽象的频谱图，直观易懂
- 用"小节通关 + 自动存档"提供成就感和进度感
- 用"最弱小节推荐 + 重复练习"实现针对性训练

### 为什么合理
| 设计决策 | 合理性 |
|---|---|
| 游戏化练习 | 降低练习枯燥感，提升持续使用意愿 |
| 导入用户自己的乐谱 | 练习用户真正想唱的歌，而非固定曲目 |
| 小节为单位存档 | 唱错不用从头来，降低挫败感 |
| 区分男女声八度 | 男声天生比女声低八度，不处理则男声永远唱不准 |
| 保留真实偏差不自动纠错 | 用户需要看到自己真实的音准问题，自动纠错会掩盖问题 |
| 显示与判定分离 | 显示原始音高让用户看到真实偏差，判定时给容错避免误判 |
| 完全离线 | 保护隐私（不上传录音），无网络也能用 |
| 体验优先于体积 | APK 尽量小，但不得为减包牺牲准确性、延迟或功能 |

## 二、核心玩法

### 一句话描述
**唱歌控制角色上下移动，在滚动的音符台阶上准确落脚。**

### 详细流程
1. 用户导入一首 MusicXML 格式的乐谱（如《小星星》）
2. App 自动解析乐谱，生成游戏地图——每个音符变成一个台阶
3. 游戏开始后，地图从下向上滚动（竖屏），角色固定在屏幕下方判定区
4. 用户对着麦克风唱歌，App 实时检测音高
5. **唱得高** → 角色向上移动（屏幕上方 = 高音，屏幕下方 = 低音）
6. **唱得低** → 角色向下移动
7. 台阶长度 = 音符时值：全音符台阶最长，十六分音符最短
8. 当音符台阶到达判定区时：
   - 唱准了 → 角色落在台阶上，台阶变绿，播放反馈音效
   - 唱高了 → 角色从台阶上方越过，台阶变红，显示"偏高"
   - 唱低了 → 角色从台阶下方穿过，台阶变红，显示"偏低"
9. 每唱完一小节，自动结算准确率并存档
10. 全曲结束后显示评级（S/A/B/C/D）和各小节准确率

### 男女声适配
- 男声默认比谱子低 8 度：谱子写 C4，男生唱 C3 即算准
- 女声按谱子原调：谱子写 C4，女生唱 C4 即算准
- 用户首次启动时选择声线，后续可在设置中切换

## 三、核心功能

### 1. 乐谱导入与管理
- 支持导入 MusicXML 格式（.xml / .mxl）
- 导入的乐谱自动保存，下次直接打开
- 支持重命名、删除
- 曲库按最近游玩时间排序

### 2. 游戏练习
- 竖屏形式，台阶从上到下代表音高从高到低
- 实时显示用户音高位置和目标音高位置
- 节拍器引导节奏（练习模式默认开启）
- 顶部进度条显示全曲进度
- 练习模式默认开启（容差宽松、不强制失败），可切换挑战模式

### 3. 小节重复练习（核心功能）
- 用户可选择单个小节或连续小节范围，针对性反复练习
- 支持无限循环或固定次数循环
- 每次循环显示准确率及与上次对比（提升/下降/持平）
- 系统自动推荐准确率最低的 3 个小节，引导用户重点练习
- 小节练习独立存档，不影响全曲进度

### 4. 自动存档
- 以小节为最小单位，每小节结束自动存档
- 异常退出（切后台、锁屏、来电）后可从最近小节恢复
- 存档写入保证原子性，防止崩溃导致数据损坏

### 5. 结算与反馈
- 全曲结束显示评级（S/A/B/C/D）、总准确率、平均偏差
- 各小节准确率柱状图，一眼看出薄弱环节
- 偏差热力图，显示偏高/偏低分布

### 6. 音高识别准确性保障（核心竞争力）
- **双算法融合检测**（YIN + fcomb 校验），八度错误率 <2%
- **前端处理链**：70Hz 高通滤波 + 噪音抑制 + 自动增益，适应不同环境和音量
- **后处理流水线**：浊音判定 → 八度纠错 → 连续性约束 → 中值滤波 → 颤音保护 → 平滑
- **环境自适应**：开局 2 秒噪音采样，动态调整检测阈值
- **用户音域校准**：测用户高低音，用于八度纠错和频率约束
- **运行时质量监控**：实时评估检测质量（置信度/稳定性/削波率），低质量时给提示
- **判定层容错**：低质量帧不直接判 miss，使用质量加权平均音高判定
- **显示与判定分离**：显示原始浮点 MIDI（真实偏差），判定用质量加权值（公平）
- 标准音 440Hz 检测准确率 ≥99%，人声检测准确率 ≥92%

### 7. 异常场景处理（24 类）
- 系统权限：首次授权、拒绝、永久拒绝、运行时撤销
- 生命周期：切后台、锁屏、来电、屏幕旋转
- 音频异常：麦克风被占用、语音助手抢占、蓝牙设备插拔、USB 音频
- 环境异常：持续静音、环境噪音大、省电模式、低存储
- 硬件异常：麦克风故障、企业 MDM 禁用、采样率不匹配

## 四、技术方案（简要）

### v1 推荐技术栈（可替换，需满足 KPI）
| 技术 | v1 推荐 | 可替换方向 |
|---|---|---|
| 开发框架 | Flutter (Dart) | Kotlin 原生、React Native |
| 音高检测 | aubio (YIN + fcomb) | CREPE、libf0、pyin |
| 音频采集 | Oboe (C++) | AAudio 直接、OpenSL ES |
| 乐谱格式 | MusicXML | — |
| 状态管理 | Riverpod | Bloc、Provider |
| 本地存储 | SQLite + SharedPreferences | Room、Hive |
| 架构 | Clean Architecture 三层 | MVVM、MVI |
| 游戏渲染 | Flutter CustomPainter | Flame 引擎 |

### 关键性能指标（硬约束）
| 指标 | 目标 |
|---|---|
| 端到端延迟 | <100ms（P50），<150ms（P95） |
| 音高检测帧率 | ≥90Hz（48kHz），≥85Hz（44.1kHz） |
| 游戏渲染帧率 | ≥60fps（中端机） |
| 标准音检测准确率 | ≥99% |
| 人声检测准确率 | ≥92% |
| 八度错误率 | <2% |
| 唱准时判 hit 率 | ≥95% |
| APK 体积 | 目标 <50MB，上限 <80MB（体验优先） |
| 冷启动时间 | <3 秒 |
| 内存峰值 | <200MB |

### 硬约束 vs 推荐实现
- **硬约束（16 条）**：浮点 MIDI 不自动纠错、延迟 KPI、坐标系统、小节存档、男女声八度、离线、准确性 KPI、业务逻辑与 UI 解耦、Android 7-16 兼容、判定层容错、显示判定分离等——不得违反
- **推荐实现（10 条）**：具体技术栈、算法、参数、架构——可替换，替换后需通过全部验收项

## 五、文字交互原型

### 场景 A：首次启动

**用户**：点击 App 图标打开应用

**APP**：显示启动页（VocalRunner logo），<3 秒后进入权限引导页

---

**用户**：看到权限引导页，点击「开始授权」

**APP**：弹出系统麦克风权限对话框

---

**用户**：点击「允许」

**APP**：进入声线选择页，显示「男声」「女声」两个大按钮

---

**用户**：点击「男声」

**APP**：保存设置，进入音域校准引导页，显示"请唱舒适的低音 3 秒"

---

**用户**：唱低音"啊——"持续 3 秒

**APP**：实时显示音高曲线，3 秒后自动记录，切换到"请唱舒适的高音 3 秒"

---

**用户**：唱高音"啊——"持续 3 秒

**APP**：显示校准结果"您的音域：C2~G3"，点击「完成」进入新手教程

---

**用户**：点击「完成」→ 依次看完 3 步教程 → 点击「开始体验」

**APP**：进入曲库页面（空状态），显示"还没有乐谱，点击右下角 + 导入"

---

### 场景 B：导入乐谱

**用户**：点击右下角「+」→ 选择「小星星.xml」

**APP**：显示解析进度条，<2 秒后"导入成功"，曲库出现「小星星」卡片

---

### 场景 C：开始游戏

**用户**：点击「小星星」卡片 → 确认练习模式开启 → 点击「开始游戏」

**APP**：显示 3 秒倒计时，同时播放节拍器预备拍

---

**用户**：倒计时结束，开始唱"1 1 5 5 6 6 5——"

**APP**：
- 屏幕显示实时音高指示线（绿色实线=显示用原始音高，半透明虚线=判定用加权音高）
- 台阶从下向上滚动，到达判定区
- 唱准 → 台阶变绿，播放"叮"音效，角色落在台阶上
- 唱高 → 台阶变红，显示"偏高 +30 音分"，角色从上方越过
- 屏幕角落质量指示器显示绿色圆点
- 顶部进度条前进

---

**用户**：第一小节唱完

**APP**：小节结算浮层"第 1 小节 准确率 75%"，自动存档，继续第二小节

---

### 场景 D：切后台 / 锁屏

**用户**：唱到第二小节中间，按 Home 键切到桌面

**APP**：立即暂停游戏和音频采集，保存当前小节进度到内存

---

**用户**：5 秒后切回 App

**APP**：显示暂停遮罩"已暂停"，按钮「继续」「当前小节重新开始」「退出到曲库」

---

**用户**：点击「继续」

**APP**：3 秒倒计时后从当前位置继续

---

### 场景 E：麦克风被占用

**用户**：游戏中有人打来电话

**APP**：检测到麦克风被中断，暂停游戏，显示"麦克风被占用"对话框，按钮「重试」「退出到曲库」

---

**用户**：通话结束，点击「重试」

**APP**：延迟 500ms 重新打开音频流，成功后显示暂停遮罩，点击「继续」恢复

---

### 场景 F：持续静音

**用户**：唱到第四小节，突然停下想歌词

**APP**：
- 5 秒无声音 → 底部提示"没有检测到声音，请对着麦克风演唱"
- 30 秒无声音 → 弹出"已暂停 30 秒，是否继续？"

---

**用户**：点击「继续」

**APP**：3 秒倒计时后继续

---

### 场景 G：低质量检测

**用户**：在嘈杂环境中唱歌，麦克风距离较远

**APP**：
- 质量指示器变黄色，提示"检测不稳定，请靠近麦克风或减小环境噪音"
- 判定层自动降低低质量帧权重，不直接判 miss
- 音高线波动较大，但判定参考线（虚线）相对平滑

---

**用户**：调整位置靠近麦克风

**APP**：质量指示器恢复绿色，提示消失

---

### 场景 H：全曲完成结算

**用户**：唱完最后一小节

**APP**：显示结算页：
- 评级：B
- 总准确率：82%
- 平均偏差：+15 音分（整体偏高）
- 各小节准确率柱状图（第 2、5 小节较低标红）
- 按钮「再来一遍」「选择薄弱小节练习」「返回曲库」

---

**用户**：点击「选择薄弱小节练习」

**APP**：自动选中准确率最低的第 2、5 小节（连续范围），进入小节练习

---

### 场景 I：小节重复练习

**用户**：看到已选中的小节范围，点击「开始练习」

**APP**：只显示第 2–5 小节地图，开始演唱

---

**用户**：唱完一遍

**APP**：显示"准确率 78%，比上次 +3%"（绿色向上箭头），2 秒后自动开始下一轮

---

**用户**：又唱两遍，准确率提升到 85%

**APP**：每次显示与上次对比

---

**用户**：点击暂停 →「退出到曲库」

**APP**：返回曲库，全曲进度不受影响（小节练习独立存档）

---

### 场景 J：设置页面

**用户**：曲库页点击右上角设置图标

**APP**：显示设置页：声线选择、重新音域校准、练习模式默认开关、节拍器开关、音高容差调节、蓝牙麦克风开关（默认关闭）

---

**用户**：开启「蓝牙麦克风」

**APP**：提示"蓝牙麦克风可能因压缩影响音高检测，建议使用有线耳机或内置麦克风"，确认后开启

---

### 场景 K：权限被永久拒绝

**用户**：首次授权时点击「拒绝」并勾选"不再询问"

**APP**：显示"请在系统设置中开启麦克风权限"页面，按钮「前往设置」

---

**用户**：点击「前往设置」→ 在系统设置中开启权限 → 返回 App

**APP**：检测到权限已授予，自动进入声线选择页
